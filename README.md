# Página da Nova TV

Apresentação pública do projeto pessoal Nova TV. Contém somente HTML, CSS, o papel de parede e este README. Não contém APK, código do launcher nem credenciais.

## GitHub Pages

A publicação pode usar estes arquivos na raiz do repositório. Em Settings > Pages, escolha a branch principal e a pasta raiz. Use a URL pública gerada no campo “URL do aplicativo” do TMDB.
